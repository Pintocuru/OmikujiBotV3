# OmikujiBot

OmikujiBotは、配信向けアプリ「わんコメ」専用のおみくじBOTを作るプロジェクトです。
BOT本体の「Generator」と、そのデータを編集する「Editor」で構成されています。

## 構成

### Generator : BOT本体 (`src/generator`)

Editorで作成した設定データ(JSON)を読み込み、
コメントへの反応、おみくじの抽選、ゲームの実行、演出の表示を行います。

### Editor : エディター (`src/editor`)

Generatorの設定データを作成・編集するエディターです。
おみくじの結果、確率、演出、コメントへの反応などをGUIで設定できます。

### UI : 配信画面に表示するUI (`src/ui`)

配信画面に表示するUI(CommentBubbleなど)です。

### Manager : データマネージャー (`src/manager`)

Editorで使用するデータを一元管理します。
エディタープラグインを導入すると使用できます。

### Games : ゲームスクリプト (`src/games`)

ジェネレーター本体で実行されるゲームスクリプトです。複雑な処理が可能で、トリガーの発生時に実行されます。

### Plugin : エディタープラグイン (`src/plugin`)

おみくじBOT専用の、わんコメプラグインです。
データマネージャーを使う場合に必要です。
ゲームの結果(スイカジェネレーターなどのランキング)を保存する機能もあります。

### Console : ライブコンソール (`src/console`)

ゲームの結果閲覧、配信へのWordParty投稿(ポン出し)、ジェネレーターをブラウザから操作できるWebアプリです。

### Server : 開発用サーバー (`server`)

開発用の、わんコメプラグインの代わりとなるものです。

### Packages : 配布パッケージ (`packages`)

配布用の製品です。パッケージごとに `main.ts` でUIとレイアウトを選び、webpackでビルドします。
無料版はGeneratorのみ、有料版はGeneratorとEditorの両方を配布します。

## ディレクトリ構造

| ディレクトリ | 内容                                           |
| ------------ | ---------------------------------------------- |
| `src/`       | すべてのソースコード                           |
| `packages/`  | 配布パッケージ(期ごとに分類)                   |
| `tools/`     | ビルド、JSONマージなどの開発ツール             |
| `docs/`      | 各製品の説明書(README)                         |
| `assets/`    | キャラクター画像、サウンド、画像素材など       |
| `server/`    | 開発用サーバー(Express)とエディタープラグイン  |
| `build/`     | 旧ビルド置き場(`packages/` へ移行中、廃止予定) |

### `src` の中身

| ディレクトリ | 内容                                                         |
| ------------ | ------------------------------------------------------------ |
| `generator/` | BOT本体(ストア、イベント処理、トリガー判定)                  |
| `editor/`    | エディター本体                                               |
| `engine/`    | おみくじ抽選、プレースホルダー、投稿処理などのコアロジック   |
| `games/`     | ゲームスクリプト                                             |
| `ui/`        | 配信画面に表示するUI(CommentBubbleなど)                      |
| `layout/`    | UIのレイアウト。パッケージごとに専用レイアウトを用意できます |
| `plugin/`    | エディタープラグイン                                         |
| `manager/`   | データマネージャー                                           |
| `sdk/`       | わんコメとの接続・購読・投稿                                 |
| `common/`    | GeneratorとEditorで共有する部品(マイグレーションなど)        |
| `maps/`      | 型に対応する定義マップ                                       |
| `i18n/`      | 多言語対応(日本語・英語)                                     |
| `types/`     | 型定義                                                       |
