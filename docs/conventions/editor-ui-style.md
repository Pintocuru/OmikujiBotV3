# エディター UI スタイルの方針

ボタン・アイコン・補足説明を、操作の意味と画面の一貫性に合わせて設計する。

- DaisyUI の `btn` を使う場合、サイズや色は配置・重要度・危険性に応じて選ぶ。全画面で同じサイズ・色に固定しない。
- 保存・確定などの主操作、通常操作、補助操作、危険操作は、見た目から区別できるようにする。色クラスは意味に合わせて選び、色だけに意味を依存させない。
- DaisyUI の `tabs` や `menu` など、専用の構造を持つ UI を無理にボタンへ置き換えない。
- アイコンのサイズ・間隔は周囲の UI と揃える。アイコンだけの操作には用途が分かるアクセシブルな名前（例: `aria-label`）を付ける。
- `tooltip` は操作の補足、`title` は省略された内容の確認などに使う。説明の重複を避ける。
- tooltip の位置・重なり・切れは、実際の配置と親要素を見て判断する。

規約に合わせるためだけに既存 UI を変更しない。見た目を変更するときは、操作性・視認性・アクセシビリティと既存コンポーネントの責務を優先する。
