# 日本語 UI 文言の方針

対象は `src/i18n` の日本語（`ja`）文言。

- ラベルやボタンは短く分かりやすくする。常体・体言止めを基本にするが、自然さや文脈に応じて表現を選ぶ。
- 重複する主語や前置きは省いてよい。ただし、短縮によって対象・条件・結果が曖昧にならないようにする。
- tooltip は短く要点を伝える。詳しい説明が必要なら別の説明領域を使う。
- 警告・注意・エラーは、短さより正確さを優先する。必要な条件・影響・対処を省かない。
- ラベルや短い語句には通常句点を付けない。文章では読みやすさに応じて句読点を使う。
- 同じ概念には既存の用語を使い、表記揺れを避ける。技術用語を無理に日本語化しない。
- 翻訳文のプレースホルダー、補間式、タグ、属性、改行、エスケープなどの構造は、文章の修正だけを理由に変更しない。

文体や文字数を機械的に統一しない。自然さ・意味の明確さ・画面上の読みやすさを優先する。
