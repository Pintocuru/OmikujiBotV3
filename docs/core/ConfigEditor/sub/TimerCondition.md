## タイマーの動作条件（判定式）

### 概要

- **目的**: 「式が成立しているときだけ、タイマーを実行する」条件を書けます。たとえば「演出中だけ流す」「5 回まで流す」といった使い方ができます。
- **上級者向けの機能です。** 条件が要らないときは、空欄のままにしてください。
- 判定式は**値を読むだけ**です。変数を書き換えるのは [評価ブロック](./VariablePlaceholder.md) です。

### 動き方

タイマーが動く時間になるたびに、式を評価します。

- **空欄**: 条件なし。毎回実行します。
- **成立（`true`）**: 実行します。
- **成立しない**: その回の実行をスキップします。**タイマー自体は動き続ける**ので、次の時間にもう一度判定します。
- **評価できない式**（書き間違いなど）: `false` として扱われ、実行しません。エラーが通知されます。

結果が数値や文字列になる式（`stock + 1` など）は、`false` として扱われます。

---

### 使える値

**評価ブロックで作った変数だけ**が使えます。変数名をそのまま書いて読みます。

- タイマーにはコメントがないので、`user`・`lc`・`price` などの**標準値は使えません**（使うと `0` として扱われます）。
- **未定義の変数は `0` として扱われます。** 変数名の打ち間違いにご注意ください。
- 変数は、ブラウザ（または OBS）を閉じるまで保持されます。**起動直後は、すべての変数が未定義（`0`）** です。

---

### 使える演算子と関数

書き方は [判定式（コメントの発動条件）](./TriggerExpression.md) と同じです。

| 種類       | 書き方                                                                  |
| ---------- | ----------------------------------------------------------------------- |
| 比較       | `==` `!=` `>` `>=` `<` `<=`（文字列は `==` `!=` で比較できます）        |
| 論理       | `and` `or` `not`                                                        |
| 四則・剰余 | `+` `-` `*` `/` `%` `^`（べき乗）                                       |
| 関数       | `min` `max` `pow` `roundTo` `abs` `ceil` `floor` `round` `trunc` `sqrt` |

- 文字列は `'happy'` のように、シングルクォート（またはダブルクォート）で囲みます。
- **使えないもの**: 代入（`=`）、複数の式（`;`）、乱数（`rand`）。

---

### 例

#### 「演出中だけ」流す

コメントのおみくじなどで、演出の開始・終了に合わせて評価ブロックで変数を切り替えます。

```text
// 演出を始めるおみくじの評価ブロック
fireworks_on = 1

// 演出を終えるおみくじの評価ブロック
fireworks_on = 0
```

タイマーの動作条件に書きます。

```text
fireworks_on == 1
```

`fireworks_on` が `1` の間だけ、タイマーが実行されます。

#### 「5 回まで」流す

タイマーが実行するおみくじの中に、評価ブロックを置きます。

```text
announce_count += 1
```

タイマーの動作条件に書きます。

```text
announce_count < 5
```

起動直後は未定義（`0`）なので、1 回目から実行されます。5 回実行すると、それ以降はスキップされます。

#### 条件を組み合わせる

```text
mode == 2 and stock > 0        // モードが 2 で、在庫が残っているとき
fireworks_on == 1 or party == 1   // どちらかの演出中のとき
not (mood == 'quiet')          // 静かモード以外のとき
```

#### 文字で切り替える

```text
mood == 'happy'
```

評価ブロックで `mood = 'happy'` のように、シングルクォートで囲んで代入しておきます。

---

### うまく動かないとき

| 症状                          | 考えられる原因                                                                                 |
| ----------------------------- | ---------------------------------------------------------------------------------------------- |
| いつも実行されない            | 変数が未定義（`0`）のままで、条件が成立しない。評価ブロックが実行されていない                  |
| `stock > 0` が最初は動かない  | 起動直後は変数が未定義（`0`）。先に評価ブロックで `stock = 3` のように代入しておく |
| エラーが通知される            | 構文エラー、`;` や `=` を使っている                                                            |
| 標準値（`lc` など）が効かない | タイマーでは使えません。コメントイベントの判定式で使ってください                               |
