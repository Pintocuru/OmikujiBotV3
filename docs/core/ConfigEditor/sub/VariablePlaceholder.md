## 評価ブロック

### 概要

- **目的**: 変数の概念を導入し、より複雑で自由度の高いおみくじ結果を表示できるようにします。
- **特徴**: 簡易的なプログラミング要素を含みます。変数を保存でき、おみくじ条件でも変数を使い条件を指定できるため、簡単な TRPG、占いランキングを実装できます。
  - `expr-eval-fork` ライブラリを使用しています。
- **役割分担**: 変数を**書き換える**のは「評価ブロック」だけです。変数の値を**表示する**のは、メッセージ側の `[[変数名]]` です。
- **チートシート**: [VariablePlaceholderCheatSheet](./VariablePlaceholderCheatSheet.md)

### 使える場所

**評価ブロックを書く場所**（変数を書き換える）

- **各シナリオ** ＞ **評価ブロック**のステップ（評価ブロック内容）
- **おみくじ項目** ＞ **制御**の「評価ブロック」欄

**変数の値を表示する場所**（`[[変数名]]` と書く）

- メッセージの本文、各 UI の入力欄（slots）
- WordParty の ID
- gameScript のクエリ文字列

**判定式**（トリガー・タイマーの動作条件）からは、変数名をそのまま書いて参照できます。

### 基本的な書式

評価ブロックには、**式をそのまま書きます**。`{{ }}` などで囲む必要はありません（囲むとエラーになります）。

- 複数の式は `;` で区切ります。
- 改行は無視されて 1 行につなげられるので、式の区切りには必ず `;` を付けます。
- `//` と `/* ... */` でコメントを書けます。

```text
// 初見詐欺カウント +1
SyokenSagi<<userId>> = SyokenSagi<<userId>> + 1;
ringo = ringo + 1
```

変数の値をメッセージに出すときは、メッセージ側に `[[変数名]]` と書きます。

```text
あなたのスコアは [[score]] 点です！
```

---

### 実行のタイミング

各ステップは、設定した**遅延秒数（`delaySeconds`）の時刻**に実行されます。評価ブロックも同じです。

- 遅延秒数が 0 のステップは、おみくじが発動した瞬間に実行されます。
- メッセージの `[[変数名]]` は、**そのメッセージを実行する時刻**の値になります。
- 同じ時刻に並べるときは、**評価ブロックのステップをメッセージより前**に置いてください。
- 投稿・表示・音は「投稿の基本遅延時間」の分だけ遅れますが、評価の時刻には加わりません。

```text
0 秒   評価ブロック  score += 10
0 秒   メッセージ    「スコアは [[score]] 点！」        ← 10 を足したあとの値
3 秒   評価ブロック  bonus = rand(1, 6)
3 秒   メッセージ    「ボーナスは [[bonus]]！」        ← 3 秒後に決まった値
```

### 機能一覧と詳細

#### 1. 変数への代入

**値を変数に保存します。**

- **書式**: `変数名 = 値`
- **変数名のルール**: 英数字と `_`（アンダースコア）が使用できます。先頭は英字か `_` にしてください。日本語や `-` は使えません。
- 一度代入した変数は、**ブラウザ（または OBS）を閉じるまで保持され続けます**。

```text
name = 'さくら'   // 文字列（シングルクォート必須）
score = 100       // 数値
copy = score      // 別の変数の値をコピー（未定義なら 0）
```

#### 2. 変数の表示（`[[変数名]]`）

**保存した変数の値を、メッセージのテキストに出します。**

- **書式**: `[[変数名]]`（`[[ score ]]` のように前後に空白があっても構いません）
- 未定義の変数は、**`[[変数名]]` のまま**表示されます。変数名の綴りを間違えたときに気づけます。
- `[[ ]]` は値を読むだけで、変数は書き換わりません。
- メッセージに `{{ }}` を書いても評価されません（そのまま表示されます）。

#### 3. 四則演算による再代入

**変数の値を使って再計算し、改めて代入します。**

- **書式**: `変数名 = 変数名 演算子 値`、または `変数名 演算子= 値`
- 使用可能演算子: `+`, `-`, `*`, `/`（`+=`, `-=`, `*=`, `/=` も使えます）
- `score += 10` は `score = score + (10)` と同じです。右辺は括弧で囲まれて計算されるので、`hp -= 1 + 1` は `hp - 2` になります。
- 数値用です。文字列をつなげるときは、`str()` を使ってください。
- **数値の範囲**: -999,999,999 ～ 999,999,999（超過時は上限/下限に丸め）
- 小数点以下は **0.01** まで有効（それ以下は丸め）

```text
score = score + 10      // score に 10 を加算
score += 10             // 同じ意味（短く書ける）
hp -= 1                 // hp から 1 を減算
attack *= 2             // attack を 2 倍
total /= 2              // total を 2 で割る
point += rand(1, 5)     // rand と組み合わせも可能
```

#### 4. 三項演算子（条件分岐）

**条件に応じて異なる値を代入します。**

- **書式**: `変数名 = 条件式 ? 真の値 : 偽の値`
- 使用できる比較演算子: `==`, `!=`, `>`, `<`, `>=`, `<=`
- 文字列は `==` で比較できます（例: `name == 'さくら'`）。大小の比較は数値で行ってください。

```text
score = score + 10;
result = score >= 50 ? 'クリア' : 'ゲームオーバー'
```

あとのメッセージで `[[result]]` と書くと、score が 50 以上なら「クリア」、未満なら「ゲームオーバー」が表示されます。

#### 5. 複数式の同時実行

**セミコロン（`;`）区切りで、複数の式を 1 つの評価ブロックに書けます。**

```text
score = 0;
hp = 100;
name = 'hero'
```

#### 6. 型変換・文字列操作関数

式内では暗黙の型変換は行われません。必要に応じて明示的な変換関数を使用します。

**`str()` — 文字列化**

- 数値や変数を安全に文字列へ変換します
- 文字列連結は必ず `str()` を使用します

```text
text = str('1/', score)
```

**`num()` — 数値化**

- 値を数値へ変換します
- 変換できない場合は `0` を返します

```text
value = num(textValue)
```

**`bool()` — 真偽値化（1 / 0）**

- `0` を `0`
- それ以外を `1` に変換します

```text
flag = bool(score)
result = bool(score) ? 'OK' : 'NG'
```

#### 7. `rand` - ランダムな数値の生成

**指定した範囲内のランダムな整数を生成します。**

- **書式**: `変数名 = rand(最小値, 最大値)`
- 四則演算とも組み合わせ可能

```text
dice = rand(1, 6);
score = score + rand(1, 10)
```

結果は、メッセージで `[[dice]]` と書いて表示します。

### 応用的な使い方とルール

#### 値の代入ルール

`変数名 = 右辺` を記述したとき、右辺は以下のルールで解釈されます。

| 記述例                    | 解釈                 | 結果                                |
| ------------------------- | -------------------- | ----------------------------------- |
| `a = 'hello'`             | シングルクォートあり | 文字列 `"hello"`                    |
| `a = 100`                 | 数値のみ             | 数値 `100`                          |
| `a = other`               | 変数名               | 変数 `other` の値（未定義なら `0`） |
| `a = score >= 10 ? 1 : 0` | `?` を含む           | 三項演算子として式評価              |

**文字列を保存したい場合は必ずシングルクォートで囲んでください。**

#### 処理の順序

`<<プレースホルダー>>` が**先に**置き換えられます。

1. **評価ブロック**: `<<プレースホルダー>>` を置き換えてから、式を評価します。
   - 例: `userId = '<<userId>>'` → `<<userId>>` が置き換えられてから変数に格納
   - 変数名にも使えます。例: `anygame_<<userId>> = 5`
2. **メッセージ**: `<<プレースホルダー>>` を置き換えてから、`[[変数名]]` を値に置き換えます。
   - 変数名にも使えます。例: `[[anygame_<<userId>>]]`

`<<プレースホルダー>>` の ID の中には `[[変数名]]` を書けます。`<<>>` を置き換えるときに、`[[変数名]]` をそのステップの時点の変数値に置き換えてから、プレースホルダーを選びます。乱数で選んだ番号でプレースホルダーを引くときに使います。

```text
【評価ブロック1】 subRand = rand(1, 8)
【評価ブロック2】 subCategory = '<<subCategory_[[subRand]]>>運'
```

- `subRand` を決める評価ブロックと、`<<subCategory_[[subRand]]>>` を書くステップは、別のステップに分けてください（同じ評価ブロックでは、`subRand` が決まる前に置き換わります）。
- 変数が未定義のときは、`<<subCategory_[[subRand]]>>` のまま残ります。
- 評価ブロックの式の中では、変数名をそのまま書きます（`rand(1, num)`）。`[[ ]]` を書けるのは、`<<>>` の ID の中だけです。

ユーザーごとの変数には `<<userId>>` を使ってください。`<<user>>` は表示用のアイコン情報を含むので、変数名に使うとエラーになります。また、ID に変数名として使えない文字（`-` など）が含まれていても、評価エラーになります。

#### エラーのとき

式の評価に失敗すると、エラーが通知されます。失敗した式から後ろは実行されません（それより前の式の結果は残ります）。よくある原因は次のとおりです。

- 式の区切りの `;` を忘れた（改行は無視されるため、`a = 1` と `b = 2` が 1 つにつながります）
- `{{ }}` で囲んだ
- 文字列をシングルクォートで囲まなかった

#### 予約語

予約語はありません。`slot0` ～ `slot9` なども、ふつうの変数名です。

各 UI の slots に変数の値を入れたいときは、評価ブロックで変数に代入しておき、slots の入力欄に `[[変数名]]` と書いてください。
