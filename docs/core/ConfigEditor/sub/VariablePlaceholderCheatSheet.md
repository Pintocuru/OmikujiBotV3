# 評価ブロック チートシート

評価ブロックには式をそのまま書きます（`{{ }}` で囲む必要はありません）。変数の値を表示するのは、メッセージ側の `[[変数名]]` です。詳しい説明は [VariablePlaceholder](./VariablePlaceholder.md) を参照してください。

## 📌 クイックリファレンス（評価ブロックに書く）

| 機能           | 書式例                             | 説明                           |
| -------------- | ---------------------------------- | ------------------------------ |
| **文字列代入** | `name = 'さくら'`                  | シングルクォート必須           |
| **数値代入**   | `score = 100`                      | そのまま数値                   |
| **変数コピー** | `copy = score`                     | score の値をコピー             |
| **加算**       | `score = score + 5`                | score に 5 を加算              |
| **複合代入**   | `score += 5` `hp -= 1`             | `+=` `-=` `*=` `/=` が使える   |
| **減算**       | `hp = hp - 1`                      | hp から 1 を減算               |
| **乗算**       | `attack = attack * 2`              | attack を 2 倍                 |
| **除算**       | `total = total / 2`                | total を 2 で割る              |
| **三項演算子** | `result = score >= 50 ? 'A' : 'B'` | 条件分岐                       |
| **ランダム**   | `dice = rand(1, 6)`                | 1〜6 の乱数を代入              |
| **文字列化**   | `text = str('1/', val)`            | 明示的な文字列連結             |
| **数値化**     | `numValue = num(textValue)`        | 文字列を数値に変換（失敗時 0） |
| **真偽値化**   | `flag = bool(score)`               | 0 以外を 1、0 を 0 に変換      |
| **複数式**     | `a = 1; b = 2; c = a + b`          | セミコロン区切り               |

## 📌 表示方法（メッセージに書く）

| 機能                 | 書式例                   | 説明                            |
| -------------------- | ------------------------ | ------------------------------- |
| **変数の表示**       | `[[score]]`              | 値をテキストに出力              |
| **変数名の動的指定** | `[[anygame_<<userId>>]]` | `<<>>` を先に置き換えてから表示 |
| **番号でプレースホルダーを引く** | `<<subCategory_[[subRand]]>>` | ID 内の `[[ ]]` を変数値にしてから `<<>>` を解決 |

未定義の変数は `[[変数名]]` のまま表示されます（綴りの間違いに気づけます）。

---

## 📝 基本：代入と表示

評価ブロックはテキストに**何も出力しません**。値を表示するには、メッセージに `[[変数名]]` と書きます。

```text
【評価ブロック】 score = 100
【メッセージ】   スコアは [[score]] 点！
→ スコアは 100 点！
```

### 値の種類

```text
name = 'さくら'   // 文字列: シングルクォート必須
level = 50        // 数値: クォート不要
copy = level      // 変数コピー: level の値が入る（未定義なら 0）
```

---

## ⏱ 実行のタイミング

評価ブロックは、そのステップの**遅延秒数の時刻**に実行されます。メッセージの `[[変数名]]` も、そのメッセージの時刻の値です。同じ時刻に並べるときは、評価ブロックをメッセージの**前**に置きます。

```text
0 秒  評価ブロック  score += 10
0 秒  メッセージ    スコアは [[score]] 点！
3 秒  評価ブロック  bonus = rand(1, 6)
3 秒  メッセージ    ボーナスは [[bonus]]！
```

---

## 🧮 四則演算

`変数 = 変数 演算子 値` のほか、`+=` `-=` `*=` `/=` が使えます（数値用）。

```text
score = 0;
score += 10;   // score = 10
score -= 3;    // score = 7
score *= 2;    // score = 14
score /= 2     // score = 7
```

右辺は括弧で囲まれて計算されます（`hp -= 1 + 1` は `hp - 2`）。文字列をつなげるときは `str()` を使います。

**数値範囲**: -999,999,999 ～ 999,999,999（超過時は上限/下限に丸め） **小数点**: 0.01 単位まで有効

---

## 🔀 三項演算子（条件分岐）

```text
// 書式: 変数 = 条件 ? 真の値 : 偽の値

score = score + 10;
result = score >= 80 ? 'S' : score >= 50 ? 'A' : 'B'
```

メッセージに `[[result]]` と書くと、score が 80 以上なら S、50 以上なら A、それ以外なら B が表示されます。

使用できる比較演算子: `==` `!=` `>` `<` `>=` `<=`（文字列は `==` で比較できます）

---

## 🎲 rand（ランダム）

```text
dice = rand(1, 6);      // 1〜6 の乱数を代入
score += rand(1, 10)    // 1〜10 の乱数を加算
```

結果は、メッセージで `[[dice]]` と書いて表示します。

---

## ⚡ 複数式（セミコロン区切り）

1 つの評価ブロックに、複数の式をまとめて書けます。**改行は無視される**ので、式の区切りには必ず `;` を付けます。

```text
score = 0;
hp = 100;
name = 'hero'
```

```text
// 初期化をまとめて書く場合などに便利
base = 50;
bonus = rand(1, 20);
total = base + bonus
```

`//` と `/* ... */` でコメントを書けます。

## ⚙️ 応用パターン

### プレースホルダーとの連携

`<<プレースホルダー>>` は先に置き換えられるので、変数名や値に使えます。

```text
// ユーザーごとのカウンター
visit_<<userId>> += 1

// 動的な変数名（<<アイテム名>> が「sword」なら sword = 100 として実行）
<<アイテム名>> = <<価格>>
```

メッセージ側も同じです: `[[visit_<<userId>>]] 回目の訪問！`

ユーザーごとの変数には `<<userId>>` を使います。`<<user>>` は表示用のアイコン情報を含むので、変数名には使えません。

### 乱数で選んだ番号でプレースホルダーを引く

```text
【評価ブロック1】 subRand = rand(1, 8)
【評価ブロック2】 subCategory = '<<subCategory_[[subRand]]>>運'; subLuck = '<<subLuck_[[subRand]]>>'
```

`subRand` を決めるブロックと引くブロックは、別のステップに分けます。

### カウンター

```text
【評価ブロック】 visitCount += 1
【メッセージ】   [[visitCount]] 回目の訪問！
```

### 条件によるメッセージ分岐

```text
【評価ブロック】 score += rand(1, 100);
                 msg = score >= 80 ? '大吉！' : score >= 50 ? '中吉' : '小吉'
【メッセージ】   [[msg]]（[[score]] 点）
```

### UI の slots に変数の値を入れる

評価ブロックで変数に代入しておき、slots の入力欄に `[[変数名]]` と書きます。

## 🚫 制限事項

1. **数値範囲**: -999,999,999 ～ 999,999,999
2. **小数点**: 0.01 単位まで（以下は丸め）
3. **変数名**: 英数字と `_`、先頭は英字か `_`（日本語や `-` は不可）
4. **文字列**: シングルクォートで囲む（ダブルクォート不可）
5. **文字列の連結**: `str()` を使う（`+` や `+=` は数値用）
6. **`{{ }}`**: 評価ブロックでは使えません（囲むとエラー）。メッセージに書いても評価されません
7. **処理順**: `<<プレースホルダー>>` → 評価ブロックの評価 / `[[変数名]]` の表示
8. **予約語**: ありません
