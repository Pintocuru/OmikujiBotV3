## このアプリは何？（Features）

### おみくじの結果を、配信中にリアルタイムで確認・操作できるコンソール

- 【おみくじBOT ライブコンソール】は、[おみくじBOT プラグイン](/core/EditorPlugin/README.md) に保存されたおみくじの結果を閲覧できるアプリです。
- ブラウザで開いて使います。配信しながら、サブモニターやタブに表示しておく使い方を想定しています。
- 閲覧するだけでなく、ジェネレーターの UI（ユーザーボードなど）を操作する機能も備えています。

### 主な機能

1. **イベントログの閲覧**
   - おみくじやゲームの結果が、時系列で一覧表示されます。
   - 誰が・いつ・どんな結果を引いたかを、配信中でも確認できます。
2. **ランキングの閲覧**
   - ゲームごとの順位・ユーザー・得点・記録時刻を確認できます。
   - 表示ラベル（例：大吉）と、比較に使う得点を併記します。
3. **ユーザー統計の閲覧**
   - 遊んだ回数・累計ポイント・自己ベスト・最後に遊んだ時刻を、ユーザーごとに確認できます。
4. **ジェネレーターの UI の操作**
   - ユーザーごとの得点を、手動で加算・調整できます。
   - ユーザーをチーム（色）で分け、チームごとの合計得点を表示できます。
   - 席順を並び替えて、OBS 上のユーザーボードに反映できます。
   - コメントしていないユーザーも、手動で追加できます。

## つかいかた (Usage)

### 起動のしかた

1. わんコメを起動し、おみくじBOT プラグインを **ON** にします。
2. 配信用のおみくじBOT（ジェネレーター）を、いつも通り OBS に表示します。
3. ブラウザで ライブコンソール（`console.html`）を開きます。

### 画面の見かた

- **更新**：最新のデータを読み込み直します。
- **イベント**：おみくじ・ゲームの記録を一覧で確認します。記録がない場合は「まだ記録がありません」と表示されます。
- **ランキング**：順位・ユーザー・得点・記録時刻を確認します。
- **チーム合計**：チームごとの合計得点をバーで表示します。
- **ユーザー統計**：ユーザーごとの回数・累計ポイント・自己ベストを確認します。
- **席順**：ユーザーの席順・チーム・得点を編集します。「手動」で追加・調整した項目が反映されます。

### ユーザーを手動で追加するには

- 「ユーザーを追加」に名前を入力し、「追加」を押します。
- コメントしていない視聴者（ROM 勢）にも、得点やチームを設定できます。

## よくある質問 (FAQ)

![](../../template/jp/faq/faq_11_infoOneComme.md)

### Q. エディターと同時に使えますか？

- 使えます。ライブコンソールは、エディターとは別のアプリです。
- ただし、エディターはプラグインなしでも動作しますが、ライブコンソールはプラグインが必須です。

### Q. わんコメの「クリア」を押すとどうなりますか？

- プラグインが保持しているユーザーリストも、リセットされます。

## トラブルシューティング (Troubleshooting)

![](../../template/jp/troubleshooting/troubleshooting_11_infoOneComme.md)

### Q. 「読み込み中...」のまま、何も表示されません

- プラグインが **ON になっていない** 可能性があります。わんコメ側で、プラグインの状態を確認してください。
- わんコメを再起動してから、ライブコンソールを開き直してください。

### Q. 「まだ記録がありません」と表示されます

- おみくじやゲームが、まだ一度も実行されていない可能性があります。
- コメントテスターで、おみくじを一度実行してみてください。
