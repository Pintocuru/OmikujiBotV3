# 邪魔者サバイバル 仕様

LiveConsole の `game` カテゴリのブラウザゲーム。別ウィンドウで開き、OBS でウィンドウをキャプチャして配信に映す。
ゲーム名・キー（`nuisanceSurvival`）は仮の名前。変えるときは、フォルダ名・`ConsoleViewMap.ts`・`registerConsoleViews.ts`・`CONFIG_GAME_KEY`・保存済みの設定ファイル名をそろえる。

## 概要

- 視聴者がコメントすると、その人の「邪魔者」が盤面に出て、居残る。
- 邪魔者がいる間、主人公のライフは減り続ける。ライフが 0 でゲームオーバー。
- プレイヤー（配信者）は、邪魔者を取り除きながら、できるだけ長く生き残る。
- 邪魔者の性質は、コメントした人の `userId` で決まる。時間が経つほど、設定の倍率に従って大きくなる。

## 盤面

- 横長の 11 列 × 8 行のマス目（`GRID_COLS` / `GRID_ROWS`）。1 マスの描画サイズは `CELL_PX`（64px）。
- マス数・マスの大きさは `scripts/nuisanceConstants.ts` の定数。変えたときは、`ConsoleViewMap.ts` の `windowSize`（盤面 + 上部バー 40px）も合わせる。
- 画面は、ウィンドウの大きさに合わせて縮尺が変わる（縦横比は保つ）。
- 邪魔者・主人公の移動と当たり判定は、すべてマス単位。

## 主人公の操作

- WASD で移動（`KeyboardEvent.code` で判定するので、IME や配列に依存しない）。斜めには動かず、最後に押したキーが優先。
- キーを押している間、一定の間隔（`HERO_MOVE_INTERVAL_SECONDS`）で 1 マスずつ動く。
- 向きのマスに邪魔者がいると動けず、**押している間だけ**「押した時間」が溜まる。必要な時間に達すると、その邪魔者を取り除ける。専用のボタンはない。
- 押すのをやめると、押した時間は減っていく（`PUSH_DECAY_RATE`）。
- ウィンドウがフォーカスを失ったら、押しているキーは全部離した扱いにする（押しっぱなし防止）。
- ゲームは止めないので、操作できないまま時間が進むこともある（仕様）。

## 邪魔者

### 出現

- ゲーム中に届いたコメント 1 件につき 1 体。同じユーザーが何度コメントしても、そのぶん増える。
- 空いているマス（主人公・他の邪魔者のいないマス）からランダムに出る。
- **上限（設定の `maxNuisances`）に達しているとき、空きマスがないときは、そのコメントを無視する。**（上限を固くすると、すぐゲームオーバーになるため）
- 無視したコメントは、出現数にも貢献度にも数えない。

### 性質（userId で決まる）

`scripts/nuisanceTraits.ts` の `getNuisanceTraits(userId)`。`userId` から作った種で、いつも同じ性質になる。
乱数を引く順番を変えると、同じ `userId` でも性質が変わる。項目を足すときは、末尾に足す。

| 種類                | 出やすさ | 動き                                         | 特徴                                                                                 |
| ------------------- | -------- | -------------------------------------------- | ------------------------------------------------------------------------------------ |
| `wanderer` ふらふら | 40%      | ランダムに歩く                               | 標準                                                                                 |
| `evader` にげる     | 20%      | 主人公から遠ざかる                           | 遠ざかれないとき（壁際）は動かない。追い込むと取り除ける                             |
| `bouncer` はねる    | 20%      | まっすぐ進み、壁・主人公に当たると反対向きへ | 速い                                                                                 |
| `bomber` ばくだん   | 20%      | ゆっくり歩く                                 | 導火線の時間が来ると、爆発して消える。毎秒のダメージは小さく、爆発のダメージが大きい |

種類のほかに、`userId` ごとに次が決まる（範囲は `TRAIT_RANGES`）。

- 移動の間隔（種類ごとの範囲）、生まれたときの大きさ、毎秒のダメージ、取り除くのに必要な時間、色。
- `bomber` だけ: 爆発までの秒数、爆発のダメージ。

### 成長

```
大きさの倍率 = 生まれたときの大きさ × growthMultiplier ^ (経過秒 ÷ growthIntervalSeconds)
```

- 上限は `MAX_SIZE_SCALE`。
- 占めるマスの一辺は、大きさの倍率を四捨五入して 1〜`MAX_FOOTPRINT`（3）。大きくなってはみ出した分は、中へ寄せる。
- 大きさは、毎秒のダメージ・爆発のダメージ・取り除くのに必要な時間のすべてに掛かる。
- 邪魔者どうしは重なってよい（主人公だけが、邪魔者のいるマスに入れない。邪魔者も主人公のマスには入らない）。

### 取り除く

```
必要な時間 = 取り除くのに必要な時間 × 大きさの倍率 × pushMultiplier
```

押す対象が複数のマスにまたがるときは、残りの時間が最も短いものを押す。

## ライフ

- 1 秒あたりの減少 = Σ（毎秒のダメージ × 大きさの倍率 × `drainMultiplier`）。
- 爆発 = 爆発のダメージ × 大きさの倍率 × `drainMultiplier` を一度に減らして、その邪魔者は消える。
- ライフが 0 になったら終了。その刻みの途中で 0 になった時刻を求めて、生存時間にする。
- 減らしたライフは、その邪魔者の持ち主（コメントした人）の貢献度（ダメージ）になる。最後の刻みは、残りのライフ分だけを数える。ゲームオーバーのとき、全員の貢献度の合計は最大ライフに等しい。

## コメントの受け取り

- OneSDK の購読（`GetOmikenComments`）で、`OmikenCommentType` に変換されたコメントを受け取る。わんコメへの接続が前提。
- 購読はマウント時に 1 回だけ。呼び直すと履歴が再配信されるため、ゲーム中かどうかは `phase` で切り替える。
- 次のコメントは邪魔者にしない。
  - 購読の最初に届く履歴（`isFirstLoad`）、わんコメのリセット（`isReset`）。
  - ゲーム中以外に届いたコメント。
  - おみくじBOT 自身の投稿（`POST_SETTINGS.botUserId`）。
- 外部コメント（`meta.isExternal`）は区別しない。テストコメントも外部コメントなので、そのまま邪魔者になる。（配信中のシャットアウトはしない）
- 届いた時刻（開始からの秒）をつけて溜め、次の更新で、その時刻の刻みで出現させる。

## 時間の進め方（隠れても止めない）

配信中に別のウィンドウを操作しても、ゲームは止めない。離席中に大量のコメントが届いてゲームオーバーになるのも仕様。

- 時間は、描画のフレームではなく**壁時計**（`performance.now`）で進める。
- シミュレーションは固定の刻み（`STEP_SECONDS` = 0.05 秒）。更新のたびに、「前回から今まで」の時間を必要な回数だけ刻んで追いつく（`advance`）。
- 更新は、`requestAnimationFrame`（見えているときの滑らかさ）と `setInterval`（`PUMP_INTERVAL_MS`。隠れて描画が止まっても進める）の両方から呼ぶ。ブラウザがタイマーを間引いても、次の更新でまとめて追いつく。
- 1 回の更新で進める刻みには上限（`MAX_STEPS_PER_ADVANCE`）がある。長く離れたあとは、数回の更新に分けて追いつく。
- ゲームオーバーの時刻は、追いつく途中の「ライフが 0 になった刻み」で決まる。生存時間は、離席中でも正確。
- 進行の関数（`scripts/nuisanceEngine.ts`）は、時計・通信・画面に依存しない純粋関数。乱数・入力・コメントは外から渡す。

### 要確認（実機）

- Windows の Chrome は、他のウィンドウに完全に覆われたウィンドウの描画を止めることがあり、OBS のキャプチャが固まる場合があるという情報がある（未検証）。ロジックと記録は進むが、映像が止まるおそれがある。別のウィンドウで覆った状態で、OBS のプレビューが動き続けるか確認すること。

## コンフィグ

- 上部バーをクリック → メニュー（タイトル・説明・コンフィグ・スタート）が開く。ゲーム中は、バーを押しても何も起きない（ゲームは止めない）。
- 変更した値は、**スタートしたときに**範囲に収めて、サーバーに保存する。保存に失敗しても、ゲームは始められる。
- 保存先: `server/game-configs/nuisanceSurvival.json`（API: `load-game-config` / `save-game-config`）。サーバーは中身を知らず、形は `scripts/nuisanceConfig.ts` のスキーマが決める。
- 読み込んだ値の形が違うときは、初期値で始めて理由を表示する（黙って直さない）。項目が足りないだけなら、足りない項目だけが初期値になる。

| 項目                    | 内容                                   | 初期値 | 範囲     |
| ----------------------- | -------------------------------------- | ------ | -------- |
| `startLife`             | 最大ライフ                             | 100    | 10〜1000 |
| `maxNuisances`          | 邪魔者の上限（超えたコメントは無視）   | 30     | 1〜200   |
| `growthMultiplier`      | 成長の倍率                             | 1.1    | 1〜3     |
| `growthIntervalSeconds` | 成長の間隔（秒）                       | 10     | 1〜600   |
| `drainMultiplier`       | ライフの減る速さと爆発のダメージの倍率 | 1      | 0.1〜10  |
| `pushMultiplier`        | 取り除くのに必要な時間の倍率           | 1      | 0.1〜10  |

範囲は `CONFIG_LIMITS`（フォームの入力範囲も同じ）。

## 画面

- 上部バー: ゲーム名・ライフ・生存時間・邪魔者の数・取り除いた数・コメント購読の状態。
- 盤面（canvas）: 主人公、邪魔者（アイコン、なければ頭文字）。爆発までの時間は赤い輪、押している進み具合は緑の輪で表示。
- メニュー: 待機中に、上部バーのクリックで開閉。
- 結果: 生存時間・取り除いた数・ダメージを与えた人（上位 5 人）。「もう一度」「メニューへ」。
- テストコメント（左下）: `H` キーで隠す / 戻す（OBS でキャプチャするとき用）。

## 記録（GameLog）

終了時に自動で記録する。保存先の配信 ID は、ウィンドウを開いた日時。同じ内容を再送しても、サーバーが二重に保存しない（`id` が同じため）。失敗したときは、結果画面の「再試行」から送り直せる。

| 内容                 | `eventKey`             | 1 件の単位                                   | `score`                    | `item`             |
| -------------------- | ---------------------- | -------------------------------------------- | -------------------------- | ------------------ |
| ユーザーごとの貢献度 | `nuisanceSurvival`     | 出現した邪魔者があるユーザー 1 人につき 1 件 | 減らしたライフ（四捨五入） | `38ダメージ / 3体` |
| ゲーム全体の生存時間 | `nuisanceSurvivalTime` | 1 ゲーム 1 件                                | 生存秒（小数第 1 位）      | `12分34秒`         |

- 生存時間は、ユーザーではなくプレイヤー（配信者）の記録。ユーザーリストにいないため、固定の `userId`（`player`）・表示名（`配信者`）で残す。
- 秒数とダメージは単位が違うので、`eventKey` を分けている（ランキングが混ざらない）。
- ユーザーの得点（`update-user-stats`）は変えない。
- 1 回に送れるログの件数には上限があるため、貢献度は分けて送る。

## テストコメント

editor の「テストコメント」と同じ仕組みで、想定ユーザー数のプール（均等 / 常連あり）から投稿者を選び、わんコメにコメントを投稿する。投稿したコメントは、本番と同じ経路でゲームに届く。

- 送信 / 自動（間隔指定）/ ×10。
- 投稿先は、わんコメの枠（サービス）の先頭。枠がなければ、その旨を表示する。

## 構成

```
NuisanceSurvival/
├─ NuisanceSurvival.vue            組み立てだけ
├─ SPEC.md                         この仕様
├─ components/                     画面の部品 (TopBar / Field / Menu / Result / TestPanel)
├─ composables/
│  ├─ useNuisanceSurvival.ts       進行・時計・コメント購読・キー入力・記録
│  ├─ useNuisanceConfig.ts         コンフィグの読み込み・編集・保存
│  └─ useTestComments.ts           テストコメントの投稿
├─ maps/NuisanceSurvivalMessageMap.ts  文言 (日本語)
└─ scripts/                        純粋関数 (テストあり)
   ├─ nuisanceConstants.ts         マス目・時間・記録名などの定数
   ├─ nuisanceConfig.ts            コンフィグのスキーマと範囲
   ├─ nuisanceTraits.ts            userId → 邪魔者の性質
   ├─ nuisanceEngine.ts            進行 (出現・移動・押す・ダメージ・追いつき)
   ├─ nuisanceRecord.ts            記録の組み立て・表示用の整形
   ├─ heroInput.ts                 WASD → 向き
   └─ rng.ts                       種から作る乱数・ハッシュ
```

サーバー側（設定の保存）: `server/core/handlers/gameConfigHandler.ts`、`src/manager/services/gameConfigApi.ts`、`src/types/api/gameConfig/`。

## エンジン（Excalibur など）

使っていない。盤面がマス単位で、当たり判定が単純なため、canvas 2D で足りる。
使うなら描画だけに使い、進行はこの純粋関数に任せること。ゲームエンジンのループは `requestAnimationFrame` 駆動で、隠れると止まるため。

## 今後の検討

- 主人公の操作にゲームパッドを足す（入力は `HeroInput` に変換する層なので、足しやすい）。
- 外部コメント（`meta.isExternal`）を、配信中は無視するか。
- 邪魔者の見た目・演出（種類ごとのスプライト、爆発のエフェクト、効果音）。
- 配布パッケージへの登録（`packages/*/console.ts` に loader を 1 行）。
