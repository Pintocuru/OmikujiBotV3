# おしくらチェイン 仕様（協力パズル）

LiveConsole の `game` カテゴリのブラウザゲーム。別ウィンドウで開き、OBS でキャプチャして配信に映す。
ゲーム名・キーは `OshikuraChain` / `oshikuraChain`。

## 概要

- 視聴者がコメントすると、その人の「アイコン」と、コメントの文字（「ことば」）が盤面に降ってくる。リスナーは、押し出す素材を供給する人。
- プレイヤー（配信者）は、アイコンとことばを**画面の外へ押し出して**得点する。得点すると**残り時間が増える**。
- 増える秒数 = 獲得秒数 × **連鎖数**。
  - 獲得秒数: アイコン（巨大化を含む）は難易度別の `iconSeconds`、ことばは `wordSeconds`（1 秒）。
  - 連鎖: 得点が続くたびに +1。得点しない動き（空きマスへの移動、外へ出ない押し出し）で切れる。**止まっているだけでは切れない**。
- 残り時間は、1 秒ごとに「**倍率**」秒減る（×1 なら等倍、×5 で上限）。0 になるとゲームオーバー。開始時の残り時間は難易度で決まり、獲得時間の上限は全難易度共通で 60 分。
- 倍率（エンジンのヒートアップ）: 1 から始まり、1 分ごとに難易度別の量で上がる（上限 ×5）。**初見（`meta.tc === 1`）のコメントで ×1 に戻す（エンジンが冷える）設定は、既定で ON。**
- アイコンは動かない・爆発しない。2 分ごとに、その後最初に出現したユーザーのアイコンが巨大化し、大きさで連鎖を伸ばせる。
- ことばは不安定な燃料で、管理しないと時間経過で爆発し、周囲を巻き込む。

## ゲームモード

メニューで選ぶ（保存する設定 `gameMode`）。

- **耐久**（`endurance`・既定）: 概要のとおり。残り時間が 0 になるまで続く。
- **タイムアタック**（`timeAttack`）: 残り時間はなく、倍率は常に 1。獲得秒数の**合計が目標（`targetSeconds`・3600 秒。仮の値）に届いた時刻でクリア**し、タイムを競う。
  - 獲得秒数は `maxSeconds` で切られない。クリア時刻は、目標に届いた得点の時刻（`endedAt`）。
  - 難易度は、獲得秒数（`iconSeconds` / `wordSeconds`）にだけ効く。
  - 目標に届かずに「やめる」と、結果は「ゲーム終了 / プレイ時間」で、記録しない。
  - 上部バーは「獲得 mm:ss / 目標 mm:ss」を出し、ヒートメーターは出さない。
- ゲームモードとコメントの源（次の節）は、独立した設定で組み合わせ自由。

## 盤面

- 横長の 11 列 × 7 行（`GRID_COLS` / `GRID_ROWS`）、1 マス 64px（`CELL_PX`）。
- 変えるときは、`ConsoleViewMap.ts` の `windowSize`（盤面 + 上部バー 40px）も合わせる。
- 画面はウィンドウの大きさに合わせて縮尺が変わる（縦横比は保つ）。
- 移動と当たり判定は、すべてマス単位。

## 主人公の操作

- WASD で移動（`KeyboardEvent.code` 判定なので、IME や配列に依存しない）。斜めには動かず、最後に押したキーが優先。
- 押している間、一定間隔（`HERO_MOVE_INTERVAL_SECONDS` = 0.14 秒）で 1 マスずつ動く。
- 向きのマスにアイコン・ことばがいると、1 マス押し出し、主人公は空いたマスへ進む。専用のボタンはない。
- 押した先に別のものがいれば、**連鎖して**一緒に押す（重さはない。重なっているものも一緒に動く）。
- 押された順（主人公に近い順）に `PUSH_WAVE_DELAY_SECONDS`（0.15 秒）ずつ動き出しを遅らせ、ウェーブのように見せる。位置は即座に変わり、遅れるのは見た目だけ（`movedAt` が未来）。
- 盤面の外へ出るものは**得点**。外へ出たものは、押された順に 1 つずつ連鎖が増える。
- 得点のあとだけ、`HERO_PUSH_INTERVAL_SECONDS`（0.5 秒）のクールダウンがかかる。得点しない動きはそのまま。
- 障害物や壁で動けないときは、動いたことにならない（連鎖は切れない）。
- フォーカスを失ったら、押しているキーは全部離した扱い。表示されている間はゲームは止まらない。

## アイコン

- コメント 1 件につき 1 個（ギフトを除く）。同じユーザーでも何度でも増える。
- 主人公・他のアイコン・ことば・障害物のいないマスからランダムに出る。**上限（`maxIcons`）に達しているか空きマスがないときは出ない**（ことばは降る）。出なかったコメントは、出現数にも貢献度にも数えない。
- 動かない。大きさ・色は `userId` で決まる（0.85〜1.15 倍。`scripts/participantIconTraits.ts`。乱数を引く順番を変えると見た目が変わるので、項目は末尾に足す）。
- **巨大化**: 開始から 2 分経過ごとに、その後最初に出現したユーザーのアイコンが 2.2 倍（2×2 マス）になる。獲得秒数は通常と同じ。空きマスがない場合は通常サイズで、機会は次のユーザーへ持ち越す。間隔は全難易度共通。
- **取り除き**: 盤面の外へ押し出す（`iconRemoved` 演出で消える）。

## 残り時間・連鎖・倍率（ヒート）

- 残り時間: 開始時は難易度別の `initialSeconds`。1 秒ごとに倍率秒減る。0 になったら終了（刻みの途中で 0 になった時刻を、倍率で割って生存時間にする）。獲得時間の上限 `maxSeconds` は 3600 秒。
- 得点のたびに連鎖数 +1、**獲得秒数 × 連鎖数** が残り時間に足される（上限を超えた分は足されない）。
- 連鎖は、得点しない動きで 0 に戻る（ことばの爆発では切れない）（`chainBreak` イベント）。
- 倍率 = min(×5, 1 + 難易度別の上昇量 × (経過秒 − 最後にリセットした秒) ÷ 60)。初見リセットが ON のとき、初見コメントでリセットする（盤面が満杯でも、ギフトでも戻る）。目立って上がっていた（1.05 超）ときだけ、`multiplierReset` イベントで知らせる。
- 倍率が ×2・×3・×4・×5 を超えるたびに、`multiplierUp` イベントで知らせる。
- 貢献度: 得点を生んだ人（外へ出たものの持ち主）が、その秒数を受け取る（上限到達中も数える）。

## ことば（コメントの文字）

- コメントの文字を `WORD_CHARS_PER_ITEM`（5）文字ずつに分けた「ことば」が降ってくる。1 コメントあたり最大 `WORD_MAX_PER_COMMENT` 個。空白だけ・本文なしなら降らない。アイコンが上限で出なくても降る。
- 1 マスの白い札。空いているマスにランダムに降る。主人公が押し出せ、アイコンと連鎖する。外へ押し出すと `wordSeconds` × 連鎖数の得点（アイコンと同じ explosion.mp3、白い破片）。
- **爆発（妨害）**: 押されないまま 5〜20 秒のランダム（`lifeSeconds`）で爆発する。
  - 周囲 8 マス（一部でも重なるアイコン・ことば）を消す。巨大化アイコンは 1 マスでも範囲に入れば消える。主人公・障害物は巻き込まれない。
  - **得点にならず、連鎖も切れず、残り時間も増えない**。巻き込まれたことばは連鎖爆発しない。
  - 画面揺れ、橙の爆発、`word-blast.mp3`（素材がなければブラウザの音で代用）。巻き込まれたアイコンは破片になる（`iconRemoved` の `cause: 'exploded'`）。
  - **押されると、爆発までの時間が最初の長さに戻る**（連鎖の途中で爆発しない。連鎖先のことばも戻る）。
- 札の右上の**円グラフ**で爆発までの残り時間を見せる（残りが少ないほど緑から赤へ。直前 2 秒は点滅）。
- 同時数上限 `WORD_MAX`（超えたら古いものから爆発させずに消す）。数値は `oshikuraChainConstants.ts` の定数（コンフィグには出さない）。
- 演出イベント: `wordSpawn` / `wordGone` / `wordExplode`（`victims` は巻き込まれたことばの id）。

## コメントの受け取り

- OneSDK の購読（`GetOmikenComments`）で、`OmikenCommentType` に変換されたコメントを受け取る。わんコメへの接続が前提。
- 購読はマウント時に 1 回だけ（呼び直すと履歴が再配信される）。ゲーム中かどうかは `phase` で切り替える。
- 次のコメントは、アイコン・ことばにしない。
  - 購読の最初に届く履歴（`isFirstLoad`）、わんコメのリセット（`isReset`）。
  - ゲーム中以外に届いたコメント、ウィンドウが非表示の間に届いたコメント。
  - おみくじ BOT 自身の投稿（`POST_SETTINGS.botUserId`）。
- 外部コメント（`meta.isExternal`）は区別しない（テストコメントも外部コメントなので、そのままアイコンになる）。
- 届いた時刻（ゲーム内の時計の秒）と初見（`meta.tc === 1`）かどうかをつけて溜め、次の更新で出現させる。

## コメントオートモード

コメントの源（保存する設定 `commentSource`）。`live`（既定）は配信のコメント、`auto` は配信に左右されない自動のコメント。

- ゲーム内の時計で **5 秒（`AUTO_COMMENT_INTERVAL_SECONDS`）ごと**に架空のコメントを 1 件入れる（`scripts/autoComment.ts`）。到着時刻は 5 秒ちょうどずつ。
- 投稿者は架空ユーザーのプール（`AUTO_COMMENT_USER_COUNT` = 50 人、`createMockUserPool`「常連あり」）、本文は `pickTestComment('chat')`、アイコンは `getAvatarUrl`。本番と同じ経路（出現・ことば・巨大化）に乗る。
- 内容は本番と同じだが、**初見扱いにはしない**（倍率リセットなし）。**配信のコメントは無視する**。わんコメへの接続は要らない（上部バーに購読状態を出さない）。
- ウィンドウが非表示の間は、コメントも入らない。
- 記録: 架空ユーザーは貢献度ランキングに混ぜない。**配信者の記録だけ**残す。

## ギフト効果（ワード保護・倍率冷却）

- ギフト（`giftPrice` が 1 円以上）で、次が発動する。
  1. **盤面上のすべてのことばを保護**（爆発しなくなり、効果終了後も永久に保護）。
  2. **保護時間中に出現したことばも保護**。
  3. **倍率を `金額 ÷ 1000` だけ引き下げる**（下限 ×1.0）。

- 金額と保護時間（`GIFT_PROTECT_TIERS`）:

| 金額             | 保護時間 |
| ---------------- | -------: |
| 1〜200 円        |     5 秒 |
| 201〜500 円      |    10 秒 |
| 501〜1,000 円    |    15 秒 |
| 1,001〜2,000 円  |    20 秒 |
| 2,001〜5,000 円  |    30 秒 |
| 5,001〜10,000 円 |    40 秒 |
| 10,001 円以上    |    60 秒 |

- 演出: 名前・金額・保護時間・冷却量を画面上部に通知（`giftReceived` イベント）。保護されたことばは右上タイマーが ★ になり、爆発しない。

## 時間の進め方

ウィンドウが非表示の間は、ゲームも止まる。再表示されたら、その状態から続ける（止まっていた間のことをあとから起こさない）。

- フレームごとの経過時間を足した**ゲーム内の時計**で進める。1 フレームの上限は `MAX_FRAME_SECONDS`。
- シミュレーションは固定刻み（`STEP_SECONDS` = 0.05 秒）。更新のたびに `advance` で必要な回数だけ刻む。
- 更新は `requestAnimationFrame` だけから呼ぶ（タイマーでの補助更新はしない）。
- 進行の関数（`scripts/oshikuraChainEngine.ts`）は、時計・通信・画面に依存しない純粋関数。乱数・入力・コメントは外から渡す。

## コンフィグ

- 上部バーをクリック → メニュー（タイトル・説明・コンフィグ・スタート）が開く。ゲーム中は何も起きない（ゲームが止まることはない）。
- ゲーム中は右上に「やめる」ボタン。2 回押し（1 回目で「もう一度押すと終了」に変わり、3 秒で戻る）。やめると、その時刻で終了（`endGame`）し、時間切れと同じ結果画面を出してゲームログに記録する。ウィンドウを閉じた場合は記録しない。
- 変更した値は **スタートしたときに** 範囲に収めて、`server/game-configs/oshikuraChain.json` に保存する（API: `load-game-config` / `save-game-config`）。形は `scripts/oshikuraChainConfig.ts` のスキーマが決め、サーバーは中身を知らない。保存に失敗してもゲームは始められる。
- 読み込んだ値の形が違うときは、初期値で始めて理由を表示する（黙って直さない）。

保存されるのは、次の 4 項目のみ。残り（`initialSeconds` / `iconSeconds` / `wordSeconds` / `multiplierRisePerMinute` / `maxSeconds` / `maxIcons` / `multiplierMax` / `targetSeconds`）は、難易度・モードから導出され、保存しない。

| 項目                     | 内容                                                        |
| ------------------------ | ----------------------------------------------------------- |
| `difficulty`             | 難易度（1〜5）                                              |
| `gameMode`               | ゲームモード（`endurance` 耐久 / `timeAttack`。既定は耐久） |
| `commentSource`          | コメントの源（`live` 配信 / `auto` オート。既定は `live`）  |
| `resetMultiplierOnFirst` | 初見コメントによる倍率リセット（既定 ON。耐久のみ）         |

旧キー `resetCoefficientOnFirst` は、読み込み時に新しいキーへ読み替える。

- 難易度は 5 段階。所要時間の目安は 1 が約 60 分、2 が約 40 分、3 が約 20 分、4 が約 10 分、5 が約 5 分（表示上の目安で、初見リセットを考慮しない。実際の所要時間を保証しない）。

| 難易度 | 初期残り時間 | アイコン獲得秒数 | ことば獲得秒数 | 倍率上昇（/分） |
| ------ | -----------: | ---------------: | -------------: | --------------: |
| 1      |       3600秒 |              8秒 |          1.5秒 |            0.05 |
| 2      |       2400秒 |              6秒 |          1.2秒 |             0.1 |
| 3      |       1200秒 |              5秒 |            1秒 |             0.2 |
| 4      |        600秒 |              2秒 |          0.4秒 |            0.35 |
| 5      |        300秒 |              2秒 |          0.4秒 |             0.5 |

数値は初期バランス案。実際のプレイ時間を見て調整する。
難易度の調整値は `DIFFICULTY_PROFILES`、共通値は `COMMON_CONFIG` で管理する。

## 画面

- 上部バー: ゲーム名・残り時間（バーと mm:ss）・ヒートメーター（倍率。上がるほど青 → 黄 → 赤。×5 で点滅）・連鎖数・経過時間・アイコン数（上限の 80% 以上で黄色、到達で赤）・コメント購読の状態・やめるボタン。
- 背景（星間旅行）: 盤面の中央から外へ星が広がる（`render/StarField.ts`。奥行き違い 140 個）。速さは連鎖数で決まり、0 連鎖でゆっくり、12 連鎖（`CHAIN_FOR_MAX_SPEED`）で最大。切れるときは 1 秒ほどかけて戻る。見た目だけで、進行には影響しない。
- 盤面（Excalibur）: 主人公、アイコン（画像、なければ頭文字。巨大化は 👑）、ことば（白い札）。
- 演出（出現）: 上から落下（着地で土煙と画面揺れ。巨大化は大きく）。
- 演出（押し出し）: 外へ出るものは、ウェーブに合わせて遅れて滑って消える。アイコンは色つき破片、ことばは白い破片、どちらも explosion.mp3。
- 演出（ことばの爆発）: 橙の大きな爆発、強い画面揺れ、`word-blast.mp3`。
- 演出（得点・連鎖）: 得点のたびに、連鎖数に応じた**音階**が鳴る（1 連鎖がド、…、8 連鎖が 1 オクターブ上のド、上限は 2 オクターブ上のド）。素材は使わず、Web Audio の三角波。連鎖のウェーブに合わせて、音も文字も少し遅れる。
  - 外へ出た場所に「+◯秒」（2 連鎖以上は「N連鎖！」も。増えるほど大きく、黄色から赤へ）。5 連鎖以上は画面が少し揺れる。
  - 連鎖が切れたとき、2 連鎖以上なら「TOTAL +◯秒！」を大きく出す（連鎖中の TOTAL は上部バーにもある）。
  - 倍率が ×2・×3・×4・×5 に上がったとき、「エンジン温度上昇！」「ヒートアップ！」「オーバーヒート寸前！」「限界突破！ 最大ヒート！」（段階が上がるほど、文字・火の粉・画面揺れが大きく、赤くなる。低い音も鳴る）。
  - 初見で倍率が戻ったとき、「◯◯ さん初見！ エンジン冷却！」。
  - 浮かぶ文字は同時 40 個まで（超えたら古いものから消す）。
- 結果: 生存時間・最大連鎖・押し出した数・時間を生んだ人（上位 5 人）。「もう一度」「メニューへ」。
- テストコメント（左下）: `H` キーで隠す / 戻す（OBS でキャプチャするとき用）。

## 記録（GameLog）

終了時に自動で記録する（保存先の配信 ID は、ウィンドウを開いた日時。`id` が同じなので送り直しても二重保存されない。失敗したときは、結果画面の「再試行」から再送）。

| 内容                         | `eventKey`                | 1 件の単位                           | `score`                                       | `item`       |
| ---------------------------- | ------------------------- | ------------------------------------ | --------------------------------------------- | ------------ |
| ユーザーごとの貢献度         | `oshikuraChainSeconds`    | 秒数を生んだユーザー 1 人につき 1 件 | 生んだ秒数（四捨五入）                        | `38秒 / 3体` |
| ゲーム全体の生存時間         | `oshikuraChainTime`       | 1 ゲーム 1 件                        | 生存秒（小数第 1 位）                         | `12分34秒`   |
| タイムアタックのクリアタイム | `oshikuraChainTimeAttack` | クリアした 1 ゲーム 1 件             | クリアまでの秒（小数第 1 位。小さいほど良い） | `20分34秒`   |

- 耐久: 貢献度（実コメントのときだけ）+ 生存時間。オートモードでは、貢献度は残さない。
- タイムアタック: クリアしたときだけ、クリアタイムを残す（やめたときは何も残さない）。貢献度は、耐久のランキングと混ざらないよう残さない。
- 生存時間は、ユーザーではなくプレイヤー（配信者）の記録。固定の `userId`（`player`）・表示名（`配信者`）。
- 生存時間と貢献度は意味が異なり、ランキングが混ざらないよう `eventKey` を分けている。
- ユーザーの得点（`update-user-stats`）は変えない。
- 1 回に送れるログの件数には上限があるため、貢献度は分けて送る。

## テストコメント

editor の「テストコメント」と同じ仕組み。想定ユーザー数のプール（均等 / 常連あり）から投稿者を選び、わんコメにコメントを投稿する。投稿したコメントは、本番と同じ経路でゲームに届く。

- 送信 / 自動（間隔指定）/ ×10。
- 投稿先は、わんコメの枠（サービス）の先頭。枠がなければ、その旨を表示する。

## 描画と演出（Excalibur）

描画と演出だけを Excalibur（`excalibur`）で行う。進行は、純粋関数（`oshikuraChainEngine.ts`）が決める（固定刻み・種からの決定性・テストを保つため）。

- 役割: ゲームロジック = `scripts/`、描画・演出 = `render/`、つなぎ = `OshikuraChainStageSource`（読み取り専用の窓口。`getState` / `getConfig` / `getClock` / `drainEvents`）。
- 状態と演出イベントは別: `advance` は、状態とは別に `events`（`iconSpawn` / `iconRemoved` / `wordSpawn` / `wordGone` / `score` / `chainBreak` / `multiplierUp` / `multiplierReset` / `giftReceived`）を返す。コンポーザブルが溜めて、盤面が `drainEvents` で受け取る。
- 演出はプリセット（`render/effectPresets.ts`）: イベント → 「何を、どれくらい派手に出すか」だけを決める。演出を足すときは、プリセットを足して、イベントに対応させる。
- 見た目（円・アイコン・輪）は、Excalibur の `Canvas` グラフィックで描く。
- `OshikuraChainField.vue` は、起動と破棄（`onMounted` / `onBeforeUnmount`）だけ。

## 素材（効果音・画像）

- 効果音の一覧は `render/stageSounds.ts`: `land.mp3`（着地）/ `boss-land.mp3`（巨大化したアイコンの着地）/ `explosion.mp3`（押し出し。キー `remove`）/ `word-blast.mp3`（ことばの爆発。キー `wordBlast`）。
- 素材は `assets/sounds/<四半期>/OshikuraChain/` に置く（配布後は `sounds/OshikuraChain/`）。画像は `images/OshikuraChain/`（`player/` `effects/` `backgrounds/` `cutins/`）にまとめる。
- 素材がなければ、その音が鳴らないだけでゲームは動く（コンソールに警告を 1 回出す）。`word-blast.mp3` がなければ、ブラウザの音（ノイズと低い音）で代用する。
- URL は `assetBase`（なければ `./`）から作る。開発サーバー（5174）では、Vite のプラグインが `/sounds/` `/images/` を `assets/` から探す。
