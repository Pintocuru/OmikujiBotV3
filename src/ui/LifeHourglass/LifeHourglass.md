# LifeHourglass(命の砂時計)実装指示 — OmikujiBotV3

実験枠の UI として、`lifeHourglass` を新規に作る。気に入れば安定版に昇格し、失敗すれば捨てる前提。

## 0. 前提

- 規約: `docs/conventions/ui-component-registry.md`(先に読む)
- 雛形: `src/ui/KujibikiPanel` と同じ構造にする(別紙「UI内コンポーネントレジストリ移行指示」と同じ規則)。
- 同接・ギフトの数値の取得: **`src/ui/StreamCounter` と `@/ui/common/useStreamCounters` を参照する**(§5)。
- 参照してよい UI: `CookieCounter`(数値表示や増加演出)、`GameRanking`(本体 / Selector / editor / layouts の構成)。
- `src/types/ui` と `src/types/api` は許可なく変更してよい。それ以外の `src/types` は変更しない。

## 1. コンセプト

視聴者が配信を見ている時間(命の一部)を「砂粒」にして貯める、ネタ寄りの配信ガジェット。

- 砂粒は **同時接続数 × 経過秒数** で増える(1 人が 1 秒見ると 1 粒)。
- ギフトでも増える。**100 円 = 600 粒**(10 円 = 1 分ぶん = 60 粒)。この係数は定数にする(設定項目にしない)。
- カウントアップのみ。時間制限・満杯・終了はない。
- 表示は、数値の増加をメインとし、サブ表記として器のアイコンの個数で表す(§3)。

## 2. 世界観

画面には表示しないが、販売の際にバックストーリーとして表示。

```text
本日集めた人生 N粒
視聴者があなたへ託した時間 N時間N分
今日も誰かの命の砂時計が ここへ注がれています
```

- 世界観: 時間は命。ポジティブな実績に見えて、よく考えると少しブラック、という塩梅にする。
- GMOの熊谷代表を尊重すること。
- 「託された時間」は、`砂粒 ÷ 3600` を時間と分に直して表示する(1 粒 = 視聴者 1 人の 1 秒)。
