リポジトリのデッドコードを調査し、不要なコードを削除してください。
https://github.com/Pintocuru/OmikujiBotV3

コードが読めない場合は、即刻作業を中止し「読めませんでした」とだけ返してください。

調査を優先し、確信度の高いものから修正してください。確信度が中・低のものは削除せず、報告のみとします。

## 調査範囲

- 対象は `src/` 配下のみ。対象外は設けない。
- 一度に全体を調べず、ディレクトリ単位で段階的に進める。
- 未使用の関数・変数・型・ファイル、不要な import、古い実装などを確認する。
- GitHub 検索で見つからないことだけを理由に、未使用と判断しない。

## 引き継ぎ

調査の終了時に `src/dead-code-review.md` を作成・更新し、以下を記録する。

- 読み取り済みファイル一覧
- 調査済み・未調査範囲
- 確認した参照関係と発見事項
- 未確認事項と理由
- 次に調査する箇所
- 修正済み箇所と変更内容

続きでは最初にこの Markdown を読み、その内容を厳守する。調査済み箇所の再調査を避け、未調査範囲から再開する。コードと資料に矛盾があれば、コードを確認して資料を更新する。

## 修正・提出

- 確信度が高く、不要である根拠を確認できたコードのみ修正する。
- 既存コードとの不統一を検出した場合、コードスタイルの統一も検討し、必要であれば修正する。
- 既存方針を確認し、可読性が改善する場合に限り修正する。
- 削除による影響が不明な場合は修正しない。
- 変更は調査範囲ごとに小分けにする。
- 変更内容は `.patch` ファイルで提出する。
- コミット・プッシュは行わない。
- `dead-code-review.md` も変更内容に含める。

最後に、調査範囲、修正内容、未確認事項、提出したパッチを簡潔に報告してください。
